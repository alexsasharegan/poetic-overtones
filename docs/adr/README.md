# Architecture Decision Records

> Why poetic-parser is built the way it is, and how to back a decision out.

## Status Legend

| Status | Meaning |
|--------|---------|
| **Proposed** | In an open pull request, waiting for Alex's approval |
| **Active** | Current, effective decision |
| **Superseded** | Replaced by a later ADR (say which) |
| **Deprecated** | No longer recommended for new work |

Number ADRs sequentially and never reuse a number. The pattern is the one in Alex's `project-docs` skill.
